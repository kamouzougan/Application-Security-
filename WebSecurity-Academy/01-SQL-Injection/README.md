
# SQL Injection — WHERE Clause

## Lab
**SQL injection vulnerability in WHERE clause allowing retrieval of hidden data**

**Platform:** PortSwigger Web Security Academy  
**Tool:** Burp Suite  
**Status:** ✅ Solved

## Objective
Identify and exploit a SQL injection vulnerability in a product filter to retrieve hidden data.

## What I Did
I used Burp Suite to intercept and inspect the HTTP request generated by the application.

I identified a vulnerable parameter and modified the request in the authorized Web Security Academy lab environment.

The modified request changed the SQL query logic and caused the application to display products that were normally hidden.

## Skills Practiced
- Burp Suite
- HTTP request and response analysis
- SQL injection testing
- Parameter manipulation
- Web application security testing
- Vulnerability verification

## Security Impact
SQL injection can allow an attacker to manipulate database queries and potentially access information they are not authorized to view.

## Remediation
Use parameterized queries (prepared statements) instead of constructing SQL queries directly from user-controlled input.

Additional protections include:
- Server-side input validation
- Least-privilege database permissions
- Secure error handling
